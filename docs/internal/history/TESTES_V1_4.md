# Checklist rápido — PDF Studio v1.4

## Organizador

1. Abra um PDF de 10+ páginas.
2. Arraste a página 5 para a posição 1.
3. Exclua uma página.
4. Selecione 3 páginas e use Extrair.
5. Abra ambos os PDFs gerados e confira ordem/quantidade.

## Editor

1. Gire uma página 90°.
2. Duplique outra.
3. Exclua uma terceira.
4. Reordene duas páginas.
5. Baixe e confira todas as alterações.

## OCR

1. Use um PDF realmente escaneado, sem texto selecionável.
2. Escolha Português / 180 DPI.
3. Gere o PDF pesquisável.
4. Abra o arquivo e use Ctrl+F para buscar uma palavra visível na página.
5. Confira se a aparência original foi preservada.

## Lote

1. Adicione 3 a 5 PDFs.
2. Use modo Inteligente.
3. Confira status individual de todos.
4. Abra o ZIP final.
5. Verifique os PDFs e `relatorio-processamento.txt`.
6. Repita com Para X MB cada.
