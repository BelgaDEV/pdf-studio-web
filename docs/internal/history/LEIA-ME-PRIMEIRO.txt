PDF Studio Web Client v1.7.1 — Legal / Business

NOVO: Preparar documento encadeia limpeza, compressão, OCR, metadados, marca d'água, numeração e PDF/A em um único fluxo.

NOVAS FERRAMENTAS:
1. Marca d'agua
2. Numeracao de paginas
3. Remover paginas em branco
4. Remover metadados
5. Proteger com senha AES-256
6. Extrair imagens incorporadas
7. PDF para PDF/A-1b / 2b / 3b

TESTE LOCAL:
1. npm install
2. npm run build
3. npm run dev
4. Teste cada ferramenta com PDFs pequenos antes de homologar arquivos grandes.

ATUALIZAR PROJETO OFICIAL SOMENTE DEPOIS DOS TESTES:

- git add .

- git push
- npx wrangler deploy

IMPORTANTE:
- O PDF Studio nao armazena a senha usada para proteger PDFs.
- O extrator trabalha com imagens raster incorporadas; vetores/texto nao sao imagens.
- PDF/A deve ser validado com uma ferramenta normativa dedicada antes de uso regulatorio.
