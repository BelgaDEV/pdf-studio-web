# PDF Studio Web v1.8.4 — Brand & Web Polish

## Alterações

- Favicon oficial da marca em SVG e PNG.
- Apple Touch Icon para atalhos em iPhone/iPad.
- Ícones 192x192 e 512x512 para manifest/PWA.
- `site.webmanifest` com identidade do PDF Studio.
- Open Graph e Twitter Card para compartilhamento mais profissional.
- Imagem social 1200x630.
- Títulos de aba dinâmicos por rota/ferramenta.
- Metadados de aplicação e tema revisados.

## Teste rápido

1. `npm install`
2. `npm run build`
3. `npm run dev`
4. Abrir a Home e conferir o ícone da aba.
5. Abrir `/tool/compress` e confirmar `Comprimir PDF — PDF Studio` na aba.
6. Adicionar a Home à tela inicial do celular e conferir o ícone.
