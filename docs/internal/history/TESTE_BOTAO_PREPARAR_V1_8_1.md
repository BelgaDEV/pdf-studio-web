# Teste v1.8.1

1. Rode `npm install`, `npm run build` e `npm run dev`.
2. Abra `/tool/prepare-document`.
3. Selecione um PDF.
4. Ative várias opções até o painel ficar maior que a tela.
5. Confirme que o botão `Preparar documento` permanece visível na base do painel direito.
6. Role apenas o painel de opções e confirme que a barra de ação continua acessível.
7. Teste em largura abaixo de 900 px e confirme que o botão aparece normalmente ao fim das opções.
8. Clique no botão e confirme que o pipeline inicia.
