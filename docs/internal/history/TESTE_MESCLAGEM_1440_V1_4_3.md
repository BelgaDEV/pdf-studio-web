# Teste — 1.440 PDFs

1. Rode `npm install`, `npm run build` e `npm run dev`.
2. Abra Mesclar PDF.
3. Selecione os 1.440 PDFs.
4. Clique em Executar agora.
5. O botão deve mudar imediatamente para Processando.
6. O card de progresso deve mostrar Modo Ultra / armazenamento temporário local.
7. Abra “Detalhes da mesclagem” para acompanhar pré-validação, lotes e consolidação.
8. Ao final, abra o PDF e confira primeiras, intermediárias e últimas páginas.

Se falhar, copie exatamente a última linha de “Detalhes da mesclagem” e a mensagem vermelha.
