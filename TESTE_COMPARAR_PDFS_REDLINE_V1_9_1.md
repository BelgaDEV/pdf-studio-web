# Teste — Comparar PDFs Redline v1.9.1

1. Compare dois PDFs idênticos. O Redline não deve inventar alterações.
2. Adicione uma frase no revisado. O trecho deve receber destaque/linha azul.
3. Remova uma frase. O Redline deve mostrar o conteúdo removido em vermelho tachado.
4. Adicione uma página inteira. Ela deve aparecer com borda e selo azul.
5. Remova uma página inteira. Ela deve permanecer no Redline com selo/borda vermelhos.
6. Troque apenas uma imagem ou elemento visual. Com comparação visual habilitada, a página deve receber sinalização laranja.
7. Abra o Redline no Edge e no Adobe Reader e confirme que o arquivo é válido.
8. Confira que o relatório PDF tradicional continua funcionando.
