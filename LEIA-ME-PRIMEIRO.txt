PDF Studio Web Client v1.4.0

NOVAS FUNCOES:
1. Organizador visual de paginas
2. OCR pesquisavel para PDFs escaneados
3. Processamento em lote
4. Editor basico de paginas

TESTE LOCAL:
1. npm install
2. npm run build
3. npm run dev
4. Teste /tool/organize, /tool/ocr, /tool/batch e /tool/edit-pages

ATUALIZAR PROJETO OFICIAL:
- copie esta versao por cima de C:\PDFStudio_Web_Client_v1 SEM apagar .git
- npm install
- npm run build
- git add .
- git commit -m "Adiciona organizador OCR lote e editor de paginas"
- git push
- npx wrangler deploy

IMPORTANTE SOBRE OCR:
No primeiro uso, o navegador pode baixar o motor/modelo do Tesseract.js.
O PDF continua sendo processado localmente e nao e enviado ao servico de OCR.
